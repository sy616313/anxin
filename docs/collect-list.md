## 一、先申请，再采集

**红线：未取得实验室负责人同意，不得拍摄、不得记录柜内试剂、不得写入任何位置信息。**

### 1.1 需要谁同意

| 层级 | 找谁 | 用来做什么 |
|---|---|---|
| 学院 | 分管实验室安全的副院长 / 实验室安全员 | 允许进入实验室、允许拍摄 |
| 实验室 | 房间安全责任人（实验室负责人） | 允许记录本柜试剂与柜位 |
| 学校 | 实验室与设备管理处（可选） | 后续推广时的背书 |

### 1.2 申请话术（微信/邮件可直接用）

> 老师您好，我们是常州大学第六届"英迈云杯"参赛团队，做的是「安芯」实验室安全台账小程序。
>
> 我们想解决的问题是：学生进实验室前，常常不知道"这两瓶能不能放一起""废液倒哪个桶"。
>
> 想申请做两件事：
> 1. 到您管理的 1—2 间实验室，记录**试剂柜编号、柜内试剂名称与大致位置**（不拍照记录药品标签细节，不记录任何人名）；
> 2. 记录**洗眼器、灭火器、急救箱的位置**，以及**校医院、保卫处、学院安全员的公开联系电话**。
>
> 我们承诺：
> - 只采位置与公用电话，**不采集任何个人信息**（姓名、学号、手机号）；
> - 不接入教务、一卡通、门禁等任何校内系统；
> - 数据仅用于本次比赛，不出校；
> - 成稿后先把清单发给您核对，您确认无误我们再使用。
>
> 如果方便，我们可以在您在场的情况下用 20 分钟完成记录。期待您的回复。

## 二、采集清单（5 类）

### 2.1 柜位信息（写入 `data/cabinets.json`）

| 采集项 | 说明 | 示例 |
|---|---|---|
| 柜子编号 | **以柜上实际标签为准**，不得自编 | `CAB-B3` |
| 柜子名称 | 现场称呼 | `B-3 试剂柜` |
| 房间号 | 与门牌一致 | `化工楼 302` |
| 楼层 | | `3F` |
| 责任人岗位 | **写岗位不写人名** | `实验室安全员` |
| 柜内试剂 | 试剂名称、（可选）规格/数量、所在层位 | `硝酸 / 500 mL / 上层左` |

> 柜内试剂必须能与 `data/reagents.json` 里的 `id` 对应上。对不上的，记下名称，回来后由 C 补录台账。

### 2.2 应急设施位置（写入应急卡，D4 使用）

| 采集项 | 粒度 | 示例 |
|---|---|---|
| 洗眼器 | 楼层 + 走廊方位 + 距离 | `3F 东侧走廊，距 302 约 15 m` |
| 应急喷淋 | 同上 | — |
| 灭火器 | 楼层 + 位置 + 类型 | `302 门口，干粉 4 kg` |
| 急救箱 | 房间 + 是否上锁 | `302 内，未上锁` |
| 安全出口 | 方向 | `东侧楼梯` |

> 检查项目表 7.2.2 要求"应急喷淋安装地点与工作区域之间畅通，距离不超过 30m"——所以**距离要记**，它本身就是一个可判定的检查项。

### 2.3 联系电话（公开信息，不采个人手机）

| 类型 | 示例 | 备注 |
|---|---|---|
| 校医院 | 只有座机 | 24 小时值班号优先 |
| 保卫处 | 座机 | |
| 学院安全员 | **岗位电话** | 不填个人手机 |
| 实验室与设备管理处 | 座机 | |

> 只记录**对外公布的岗位电话**。个人手机号一律不记录，即使对方主动给。

### 2.4 院规（比教育部规范更严的部分）

| 采集项 | 说明 |
|---|---|
| 学院自订的存放要求 | 例如"过氧化物必须单独上锁柜" |
| 废液分类口径 | 本院用几个桶、怎么标 |
| 准入要求 | 除了学校考试，学院是否另有要求 |
| 违禁清单 | 本院明令禁止的试剂或操作 |

### 2.5 现场照片（可选，需单独许可）

若老师同意拍照：只拍**柜体外观、标识牌、洗眼器位置**，不拍药品标签细节，不拍人脸。

## 四、如果拿不到许可怎么办

按任务书 §8.1 的"非假数据"判定口径：

- 启用**人工构造的示例柜**（`CAB-DEMO-*`），并在页面与答辩稿中**明确标注「示例柜」**；
- 标注过的示例柜**算通过 G2**，不算作弊；
- 但"真实柜位"是本项目"豆包拿不到的那部分"的核心证据，拿不到会在"个人成长"叙述上扣分。

**所以这一条要第 1 天就发出去，不要等到 D3。**
