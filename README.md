## 这是什么

在高校实验室里，学生最常犯的错不是"不会做实验"，而是"这两瓶能不能放一起""废液倒哪个桶"。这些答案现在散落在墙上的制度牌、几百页的 PDF、师兄的脑子里——都不可靠。

通用大模型能答"硝酸是氧化剂"，但它不知道**你们 B-3 柜里有硝酸、隔壁柜里放了乙醇、这个组合已经存在三个月**，答完就走，不留记录，迎检时拿不出任何东西。

「安芯」做的不是问答，是把**试剂台账、规则库、检查记录**串起来，让合规状态可计算、可留痕、可导出。

> **自检标准**：删掉问答之后，如果还剩台账、规则库、组合检查、隐患记录——项目成立；如果什么都不剩——那就是套壳，必须重做。

## 技术路线

```
上层  场景界面：查试剂 / 查柜 / 应急 / 迎检导出（微信小程序）
中层  规则引擎 + 本地知识库 + 台账数据库      ← 核心资产，护城河
下层  通用大模型（意图识别、语言转换）        ← 可替换，不是护城河
```

**不造模型，造模型落地的那一层。** 判定走规则引擎（确定性、可溯源），模型只做翻译。

## 快速开始

```bash
# 1. 校验数据是否符合契约（非零退出即不合规）
python scripts/validate_data.py

# 2. 跑规则引擎单测
node engine/test/run.js

# 3. 小程序：微信开发者工具 → 导入 miniprogram/ → 使用测试号
```

> D1 之后上述命令才可用。当前仓库为空骨架。

## 红线

不爬校内系统 · 不写个人信息 · 不提交密钥 · 规则必须有条款出处 · 不编营收模型 · 不让大模型直接下安全结论。
