## 5. 踩坑记录

| 现象 | 原因 | 解决办法 |
|---|---|---|
| **查证发现 `8.1.1` 是「实验室用电安全」（第 102 目），不是化学安全** | 网上多处把「化学安全」默认成第 8 章；实际它排在「基础安全」之后 | 不得按章号推测条款号。规则一律先填 `TODO-占位`，拿到官方 PDF 再替换 |
| 公开页面抓不到「化学安全」章 | 该表 1000+ 条，网页抓取在第六章附近即被截断；试了 6 个镜像与 PDF 均未取到 | 只录已取到的部分，缺口写进 §3；不猜 |
| 小程序 `require('../../engine/index.js')` 报错 | 小程序不能引用工程根目录之外的文件 | `sync_data.py` 增加引擎拷贝（D-02） |
| Python 脚本在 Windows 控制台输出中文乱码 | 默认 stdout 编码是 GBK | 两个脚本开头 `sys.stdout.reconfigure(encoding="utf-8")` |
| `validate_data.py` 的统计信息打印在 `sync` 之后 | 子进程先 flush，父进程 stdout 被缓冲 | 同样用 `line_buffering=True` 解决 |
| 生成 `dataset.js` 时把 `dataVersion` 丢在注释里，页面拿不到 | 只写了注释没写导出字段 | `dataVersion` 并入 `module.exports` 对象 |
