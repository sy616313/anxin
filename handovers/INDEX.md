## 用法

1. 阶段结束后，复制 `_TEMPLATE.md` → `handovers/<阶段>.md`
2. 填完九项强制内容
3. 在本表**追加一行**（不要覆盖历史）
4. `git commit` + `git push origin main`
5. 推送后核对 `git rev-parse HEAD` 与 `git rev-parse origin/main` 一致

## 约定

- 阶段命名：开发日 `D1`…`D5`；闸门 `G1`、`G2`；发布 `v0.1-demo`、`data-v1.0`
- 结论只用三种表述：**能** / **不能** / **有条件能（写明条件）**
- 历史行**永不删除**。写错了就再追加一行更正，保留痕迹
